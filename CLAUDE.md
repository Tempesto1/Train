# Рабочие веса — дневник тренировок

Личное веб-приложение (PWA) для записи силовых тренировок и кардио по неделям и сравнения рабочих весов с прошлыми неделями. Сайт публикуется через GitHub Pages из ветки `main`, папка `/` (корень): https://tempesto1.github.io/Train/

## Структура
- `src/app.html` — **исходник приложения, все правки делаются здесь.** Это фрагмент страницы без `<!doctype>/<head>/<body>`: в таком виде его же публикуют как артефакт Claude (версия на claude.ai: https://claude.ai/artifact/7ikWVGZR5ncMebp28f1VWs).
- `tools/build.js` — собирает из `src/app.html` версию для телефона: `index.html` (с PWA-метатегами и регистрацией service worker), `manifest.webmanifest`, `sw.js` (каждая сборка получает новую версию кэша).
- `tools/icon.js` — рисует `icons/*.png` (штанга с блинами в цветах дней). Нужен playwright с chromium.
- `index.html`, `manifest.webmanifest`, `sw.js`, `icons/` в корне — **собранный результат, руками не править.**

## Как выпустить новую версию
1. Изменить `src/app.html`.
2. `node tools/build.js` (иконки: `node tools/icon.js`, только если менялся их рисунок).
3. Проверить страницу на ширине телефона (390px), в светлой и тёмной теме.
4. Закоммитить исходник вместе с собранными файлами и запушить в `main`. Pages обновится примерно за минуту, а у пользователей новая версия подтянется при следующем запуске (`sw.js` загружает страницу сначала из сети).
5. Если нужно, опубликовать тот же `src/app.html` в артефакт на claude.ai.

## Данные
- Версия для телефона хранит всё в `localStorage` устройства: `rv.sessions.v1` (тренировки) и `rv.profile.v1` (вес тела и возраст). На сервер ничего не уходит. Формат хранения менять только с миграцией старых записей: потеря данных у пользователя необратима.
- Версия на claude.ai хранит те же документы в базе артефакта (`sessions/<год>-W<нед>_<тип>`, `profile/me`); правила доступа — читать и писать может только владелец.
- Перенос между версиями: «Прогресс» → «Скопировать данные» / «Восстановить из копии» (JSON `{profile, sessions}`).

## Модель
- Неделя: ISO, начинается с понедельника, ключ `2026-W45`. Тренировка: `{week, type, date, exercises|cardio, note}`, где `type` ∈ `back | legs | chest | cardio`.
- Дни: спина + бицепс; ноги (+ плечи по желанию); грудь + трицепс (+ плечи по желанию); кардио.
- Упражнение: `{name, muscle, bw, sets}`. Обычный подход: `{w, r}`. С собственным весом (`bw: true`): `{x, r, bw}`, где `x` — доп. вес (пусто = 0), `bw` — вес тела на момент подхода; в расчётах берётся `bw + x`.
- «Совокупность весов» = сумма вес × повторы за неделю. Пустые поля кардио считаются нулём.
- Прогресс по упражнению: лучший рабочий вес, а при равном весе — больше повторов.
